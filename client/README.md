### Client ver 0.0.5


### How to start it up (on Ubuntu):
1. Clone the repo
```bash
git clone git@github.com:M-M-duo/PRIYOMysh.git
```
2. Reach the client repo:
```bash
cd client
```
3. Start setup for dependencies
```
chmod +x install_dependencies.sh && ./install_dependencies.sh
```
4. Give permission for run-file and start it:
```bash
chmod +x run.sh && ./run.sh
```
5. Run modes:
```bash
./run.sh     // to build app only
./run.sh -t  // to build app and tests
./run.sh -nb // to run pre-built app
```
